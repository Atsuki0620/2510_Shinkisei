# 特許新規性分析支援システム（新規性くん）

発明アイデアと公知文献を比較分析し、新規性・進歩性を評価するAI搭載システムです。

## 🎯 主な機能

- **新規性・進歩性評価**: 発明アイデアと公知文献を比較し、特許法第29条に基づいて判定
- **公知文献比較分析**: 類似点・相違点を詳細に抽出・評価
- **追加アイデア提案**: 新規性・進歩性が不足する場合、改善案を3〜5件提案
- **クレーム提案**: 特許請求の範囲の文言案を複数パターン生成
- **レポート出力**: 分析結果をMarkdown/テキスト形式でダウンロード

## 🛠️ 技術スタック

- **UI**: Streamlit 1.28.0以上
- **言語**: Python 3.9以上
- **AI**: OpenAI GPT-4 Turbo
- **PDF処理**: PyMuPDF (fitz)
- **その他**: LangChain, python-dotenv

## 📋 必要要件

- Python 3.9以上
- OpenAI APIキー
- インターネット接続環境

## 🚀 セットアップ手順

### 1. リポジトリのクローンまたはダウンロード

```bash
git clone <repository-url>
cd "2510 新規性くん"
```

### 2. 仮想環境の作成（推奨）

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate
```

### 3. 依存パッケージのインストール

```bash
pip install -r requirements.txt
```

### 4. 環境変数の設定

`.env.example`をコピーして`.env`ファイルを作成します：

```bash
# Windows
copy .env.example .env

# macOS/Linux
cp .env.example .env
```

`.env`ファイルを編集し、OpenAI APIキーを設定します：

```
OPENAI_API_KEY=your_actual_openai_api_key_here
```

> **重要**: OpenAI APIキーは[OpenAIのウェブサイト](https://platform.openai.com/api-keys)で取得できます。

### 5. アプリケーションの起動

```bash
streamlit run app.py
```

ブラウザが自動的に開き、`http://localhost:8501`でアプリケーションが表示されます。

## 📖 使い方

### 1. 発明アイデアの入力

以下の4項目を入力します（すべて必須）：

- **技術分野**: 発明が属する技術分野（例: AI・機械学習、機械工学）
- **解決したい課題**: 従来技術の問題点や解決すべき課題
- **解決手段**: 発明の具体的な内容・仕組み・特徴
- **効果**: 発明によって得られる効果・利点

### 2. 公知文献のアップロード

- 特許明細書などのPDFファイルをアップロード
- 最大10ファイルまで（1ファイルあたり20MBまで）
- テキストPDFのみ対応（OCR非対応）
- アップロード後、ファイル名・サイズ・ページ数が表示されます

### 3. 分析実行

「🚀 分析実行」ボタンをクリックします。

- 各公知文献との比較分析
- 新規性・進歩性の総合評価
- 必要に応じて追加アイデアの提案
- クレーム案の生成

> **注意**: 分析には数分かかる場合があります。公知文献の数や内容量により処理時間が変動します。

### 4. 結果の確認

4つのタブで結果を確認できます：

#### 📋 公知文献比較
- 各公知文献との類似点・相違点
- 相違点の技術的意義

#### 📈 評価詳細
- 新規性の判定結果と理由
- 進歩性の判定結果と理由

#### 💡 提案内容
- **追加アイデア提案**（新規性・進歩性が不足する場合）
  - 追加すべき技術的特徴
  - 実装難易度（低/中/高）
  - 差別化ポイント
- **クレーム提案**
  - 上位概念/中位概念/下位概念の複数パターン
  - 重要な技術的特徴

#### 📄 レポート
- 分析結果の全体サマリー
- Markdown/テキスト形式でダウンロード可能

### 5. 結果のダウンロード

レポートタブから、分析結果をMarkdownまたはテキスト形式でダウンロードできます。

## ⚙️ システム仕様

### 対応フォーマット

- **入力**: PDF形式（テキストPDF）
- **出力**: Markdown形式、テキスト形式

### 制限事項

- 画像PDFは非対応（OCR機能なし）
- 図面・画像の解析は非対応
- 日本語文献のみ対応（英語は非対応）
- オフライン動作不可

### 性能

- PDF処理: 1ファイルあたり約10秒以内
- 分析処理: 全体で約3分以内（公知文献5件の場合）
- 推奨ユーザー数: 同時1ユーザー（ローカル実行）

## 🔒 セキュリティ

- APIキーは環境変数で管理（`.env`ファイルは`.gitignore`に追加）
- アップロードされたPDFはセッション中のみメモリ保持
- OpenAI APIとの通信はHTTPS

## 🐛 トラブルシューティング

### アプリケーションが起動しない

```bash
# パッケージの再インストール
pip install --upgrade -r requirements.txt
```

### APIエラーが発生する

- `.env`ファイルにAPIキーが正しく設定されているか確認
- OpenAI APIの利用制限に達していないか確認
- インターネット接続を確認

### PDFが読み込めない

- PDFがテキスト形式であることを確認（画像PDFは非対応）
- ファイルサイズが20MB以下であることを確認
- PDFが破損していないか確認

### 分析結果が表示されない

- ブラウザのコンソールでエラーを確認
- Streamlitを再起動してみる：
  ```bash
  # Ctrl+Cで停止
  streamlit run app.py
  ```
